# ToDo List App - React + Vite

This is a simple and minimal ToDo List web app built using React and Vite. It allows users to add, delete, and manage daily tasks in an intuitive interface.

GitHub: [ToDoList Repo](https://github.com/PercyJacker/ToDoList)

Currently, it includes:

- Adding and deleting tasks
- Clean UI with responsive design
- Local state management using React hooks
- Real-time UI updates without page reloads

## 🚀 Getting Started

```bash
git clone https://github.com/PercyJacker/ToDoList.git
cd ToDoList
npm install
npm run dev
